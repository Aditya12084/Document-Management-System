# Document Management System

A web-based Document Management System developed using Java, Spring Boot, JSP, and MySQL. The application allows users to upload, manage, and track documents securely with role-based access control.

## Features

* User login and authentication
* Admin and User dashboards
* Document upload and management
* Role-Based Access Control (RBAC)
* Document status tracking

## Tech Stack

* Java
* Spring Boot
* JSP
* MySQL

## Run the Project

1. Configure MySQL database
2. Run the Spring Boot application
3. Open:

```bash
http://localhost:8080
```
